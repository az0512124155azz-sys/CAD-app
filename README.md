# צורה — Tsura CAD

סטודיו מידול תלת־ממד הנדסי הפועל כולו בדפדפן — ללא שרת, ללא התקנה.
שפת העיצוב בהשראת Shapr3D, עומק הכלים בהשראת Fusion 360, ופשטות השימוש בהשראת Tinkercad.

## הפעלה

האפליקציה היא אתר סטטי. כל התלויות ארוזות בריפו (תיקיית `vendor/`) ואין צורך ב-build:

```bash
npm start          # או: python3 -m http.server 8080
# ואז לגלוש אל http://localhost:8080
```

> נדרש שרת סטטי (ולא פתיחת הקובץ ישירות) בגלל ES Modules.

## יכולות

### מידול
- **סקיצה ואקסטרוזיה** — שרטוט מצולע חופשי, מלבן או מעגל על מישור העבודה (מעבר אוטומטי למבט-על אורתוגרפי, הצמדה לרשת, בדיקת חיתוך-עצמי) ומשיכה לגוף תלת־ממדי בגובה מדויק.
- **מערכים (Patterns)** — שכפול ליניארי לאורך וקטור או מעגלי סביב ציר, עד 60 עותקים, כפעולה אחת בהיסטוריה.
- **שיקוף (Mirror)** — על מישור דרך הראשית או דרך מרכז הגוף, עם אפיית טרנספורם והיפוך ליפוף פאות לתוצאה תקינה להדפסה.
- **12 גופים פרמטריים** — תיבה, גליל, כדור, חרוט, טבעת, טריז, צינור, קפסולה, מנסרה, פירמידה, דיסקה וגלגל שיניים. כל פרמטר ניתן לעריכה מספרית מדויקת בכל עת.
- **פעולות בוליאניות אמיתיות** — איחוד, חיסור וחיתוך מבוססי BVH‏ (three-bvh-csg). כל תוצאה עוברת צנרת ניקוי: הסרת משולשי sliver לפי יחס גובה/צלע, איחוי קודקודים, חישוב נורמלים מחדש עם זווית קיפול ואימות ספרתי — ללא חורים, ללא עיוותי הצללה.
- **קצוות-מאפיין (Feature Edges)** — מתאר הנדסי שמצויר רק על קצוות דיהדרליים אמיתיים, עמיד בפני צמתי-T של תוצאות CSG.
- **גיזמו מלא** — הזזה, סיבוב וקנה מידה עם הצמדה לרשת (מרחק וזווית) הניתנת לכיוון.
- **עריכה מספרית** — מיקום, סיבוב, מידות כוללות (עם נעילת יחס), חומר PBR‏ (צבע, חספוס, מתכתיות, אטימות), ותמיכה בביטויים חשבוניים בשדות (`30/2`, `12+5`).

### תצוגה
- **מצלמה כפולה** — פרספקטיבה ↔ אורתוגרפית במעבר חלק ששומר על המסגור.
- **קוביית ניווט** — שישה מבטים סטנדרטיים בלחיצה + מבט ISO.
- **מבטי חתך** — מישור גזירה בכל ציר, היסט מדויק, היפוך כיוון וחיווי ויזואלי.
- **רשת עבודה הנדסית**, צללים רכים, מסגרת קווית ומדידת מרחק בין נקודות (כולל ΔX/ΔY/ΔZ).
- **יחידות** — מ"מ / ס"מ / אינץ' בכל שדות התצוגה והקלט.

### קבצים
- **ייצוא**: STL (בינארי + ASCII), OBJ + MTL, PLY בינארי, GLB (מומר למטרים לפי תקן glTF), תמונת PNG ברזולוציה כפולה, וקובץ פרויקט `.tsura` מלא.
- **ייבוא**: STL / OBJ בבחירת קובץ או בגרירה לקנבס.
- **שמירה אוטומטית** ל-localStorage ושחזור בפתיחה.

### היסטוריה והפקה
- **Undo/Redo מלא** בתבנית Command + רצועת היסטוריה ויזואלית עם קפיצה לכל נקודה בציר הזמן.
- **הפקת וידאו מהדפדפן** — Turntable ‏360° או Build Replay (שחזור מונפש של תהליך הבנייה), עד 32Mbps, יורד כ-WebM.

## קיצורי מקלדת

| מקש | פעולה | מקש | פעולה |
|---|---|---|---|
| `Q/W/E/R` | בחירה / הזזה / סיבוב / קנה מידה | `F` / `Shift+F` | התמקדות / מסגור הכל |
| `A` / `S` | גופים בסיסיים / סקיצה | `G` / `Z` | רשת / מסגרת קווית |
| `M` / `X` | מדידה / חתך | `H` / `Del` | הסתרה / מחיקה |
| `Ctrl+Z/Y` | בטל / בצע שוב | `Ctrl+D` | שכפול |
| `Ctrl+S/O` | שמירה / פתיחה | `Numpad 5` | פרספקטיבה/אורתוגרפי |

## ארכיטקטורה

```
index.html            שלד המסך (RTL, עברית)
css/main.css          מערכת עיצוב — טוקנים, פריסת Grid, תגובתיות
js/
  main.js             App — חיווט כל המערכת
  core/
    Viewport.js       רנדרר, תאורה, מצלמות, בקרות, בחירה
    SceneManager.js   מודל הנתונים — SceneObject, בחירה, אירועים
    Commands.js       Undo/Redo — פקודות + היסטוריה עם מצביע
    Units.js          מערכת יחידות (פנימי: מ"מ)
  geometry/
    Primitives.js     סכמות גופים פרמטריים
    BooleanEngine.js  CSG מבוסס BVH + טיפול בשגיאות
    GeometryUtils.js  ניקוי, sliver-filter, feature edges, נפח/שטח
  tools/              SectionTool, MeasureTool, SketchTool
  io/                 Exporters, Importers, Project (סריאליזציה)
  replay/Recorder.js  MediaRecorder — Turntable / Build Replay
  ui/                 Inspector, SceneTree, HistoryStrip, Toasts, icons
vendor/               three.js + three-bvh-csg ארוזים מקומית
```

הכול JavaScript מודולרי טהור (ES Modules + Import Maps) — ללא צעד build.
