❓ Common Questions

💰 Which AI API should I choose?

Claude: Best overall, great for everything. GPT-4: Excellent analysis. Gemini: Free tier available, good for video.

🔒 Is my data private?

Yes! 100%. Screenshots go ONLY to your chosen AI API. We never see your data. Your API key stays on your computer.

🔄 Can I use multiple API keys?

Absolutely! Configure as many as you want. Switch between them anytime. Use different APIs for different tasks.

🌐 Do I need internet?

Yes, internet is needed to use AI features. Screenshots work offline, but AI analysis requires a connection.

💳 Will it cost money?

Only if you use paid AI APIs. All APIs have free tiers. Gemini has free tier always. Claude/OpenAI charge per usage.
